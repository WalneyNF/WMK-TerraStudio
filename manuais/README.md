# Manuais WMK TerraStudio

Esta pasta é o local oficial da documentação em **português brasileiro** do fork WMK TerraStudio.

**Personalização:** Walney Moreira Klein — walneyk@hotmail.com.

## Organização planejada

| Nível | Material | Conteúdo |
| --- | --- | --- |
| Iniciante | `01-primeiros-passos.md` | Instalação, abertura do programa, tela inicial e mapa de exemplo |
| Intermediário | `02-mapas-e-camadas.md` | Dados, projeções, camadas, edições e ferramentas cartográficas |
| Avançado | `03-geoprocessamento.md` | Análises, modelos, arquivos raster e automações |
| Desenvolvedores | `04-desenvolvimento.md` | Cargo, bibliotecas, plugins, Python, CLI e MCP |
| Integrações | `05-integracoes-wmk.md` | WMK Geo Bridge, GPS Tracker e Geo Intelligence |

Os arquivos específicos dos níveis acima são **planejados** e não devem ser considerados concluídos até sua publicação.

## Regras editoriais

1. Escrever em português brasileiro com exemplos reais e verificáveis.
2. Explicar o significado dos termos GIS na primeira ocorrência.
3. Distinguir recursos existentes no RustGIS de funcionalidades futuras WMK.
4. Indicar o sistema operacional, a versão e as dependências de cada exemplo.
5. Manter exemplos de código com comandos copiáveis e resultados esperados.
6. Preservar os créditos do projeto original e as licenças de terceiros.
